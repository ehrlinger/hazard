Compute \(\ln\!\left(\frac{e^{\beta x} - 1}{\beta}\right)\), \(\beta > 0,\ x > 0\).

This expression arises in the early-phase transform as the log of the integrated exponential growth function \(B(t) = (e^{\delta t}-1)/\delta\).

For \(\beta x > 0.2\): computed as hzd_ln_eX_min1( \(\beta x\)) − ln( \(|\beta|\)). For \(\beta x \leq 0.2\): uses the Taylor series \(\frac{e^{\beta x}-1}{\beta} = x + \frac{\beta x^2}{2!} + \frac{\beta^2 x^3}{3!} + \cdots\) to avoid 0/0 cancellation as \(\beta \to 0\) (the series → \(x\)).

Parameters
BETAScale factor \(\beta > 0\).

Note
Error codes: 1 = hzd_ln_eX_min1 range error, 2 = \(\beta \leq 0\) or \(x \leq 0\).
