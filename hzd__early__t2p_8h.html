void hzd_early_t2p ( void  )

Map unconstrained optimizer theta[] back to early-phase model parameters.

Inverts hzd_early_p2t(): converts theta[0..3] from Common.theta[] to early-phase model parameters written into the TempE (temporary early) global struct:

theta index Target Inverse transform
0 TempE.delta \(-e^{-e^{\theta_0}}\) (with sign from Early.deltaN)
1 TempE.tHalf \(e^{\theta_1}\)
2 TempE.nu \(e^{\theta_2}\) (negated if g1flag ≥ 5)
3 TempE.m \(e^{\theta_3}\) (negated if g1flag ≥ 3)

Only indices where Common.status[i] == 1 are updated.

Note
Calls hzd_Error() on overflow (fatal, error code 1).

hzd_early_p2t() for the forward transform.
