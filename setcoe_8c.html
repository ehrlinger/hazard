Detailed Description

Conservation-of-events coefficient setup — main entry point.

Implements Turner's Conservation of Events Theorem (M.E. Turner Jr. PhD, notes of February 14, 1985). For a model CF(t) = G(θ)·D(t), at maximum likelihood the MLE satisfies:

\[ \sum_{i=1}^{N} CF(t_i;\hat{\theta}) = \sum_{i=1}^{N} E(i) \]

This identity allows one scaling parameter to be determined analytically as a ratio of event counts to cumulative hazard sums, reducing the optimizer's free parameter count by one.

The implementation is split across:

  • setcoe_setup_indices.c — index determination
  • setcoe_obs_loop.c — per-observation accumulation
  • setcoe_calc_scaling.c — scaling parameter solution

FORTRAN origin: llike91/setcoe (SETCOE subroutine, 1991/1994/1996 revisions).

void setcoe ( void  )

Set up conservation-of-events coefficients and solve explicit scale.

  1. Identifies which scaling parameter (μ₁, μ₂, or μ₃) can be solved non-iteratively from the conservation constraint \(\sum CF(t_i) = \sum E(i)\).
  2. Precomputes shaping functions for phases with all parameters fixed.
  3. Iteratively updates the explicit scale until convergence.
