Detailed Description

G1/SG1 variant: unconstrained M parameter (float, not integer flag).

Mirrors hzd_ln_G1_and_SG1.c but accepts M as a continuous parameter rather than dispatching on g1flag integer cases. Used in code paths where M is being estimated rather than pre-classified.

FORTRAN origin: model91/dlg1 variant paths.
