double hzd_ln_1min_enegX ( double  X)

Compute \(\ln\!\left(1 - e^{-e^x}\right)\).

Equivalent to evaluating \(\ln(1 - e^{-u})\) (see hzd_ln_1min_e_negeX()) at \(u = e^x\), but accepts the argument in log form to preserve precision when \(u\) is very small or very large.

Four regions (in terms of \(x\)):

  • \(x > 5.159\): \(e^x \geq 174\), \(e^{-e^x} \approx 0\), return 0.
  • \(0.834 < x \leq 5.159\): \(e^x > 2.30\); use series expansion.
  • \(-2.25 \leq x \leq 0.834\): stable, compute directly.
  • \(-35.351 < x < -2.25\): \(e^{-e^x} \approx 1\); use Taylor series.
Parameters
XLog of the effective argument, i.e., \(\ln(u)\) where the underlying expression is \(\ln(1 - e^{-u})\).
Returns
\(\ln(1 - e^{-e^x})\).
