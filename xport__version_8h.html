Detailed Description

SAS XPORT format version detection (V5 vs V8).

Pure function: classify the SAS XPORT "header #2" record (80 bytes) as V5, V8, or unknown. No I/O, no global state — testable. Added in v4.4.6.

Classify the second 80-byte header record of a SAS XPORT file.

Checks the 8-byte format identifier at bytes 20–27:

  • "LIBRARY " → V5 (classic SAS XPORT format)
  • "LIBV8 " → V8 (SAS XPORT V8 — rejected by hazard, exits with HAZARD_EXIT_XPORT_V8_REJECTED)
Parameters
bufPointer to header bytes (need not be null-terminated).
lenNumber of valid bytes in buf; must be ≥ 80.
Returns
XPORT_VERSION_V5, XPORT_VERSION_V8, or XPORT_VERSION_UNKNOWN.
