Compute \(\ln(A/B)\) with domain error gating.

A simplified wrapper that checks A > 0, B > 0, A/B > 0, and that the ratio is within representable range, then returns ln(A/B) directly. For A/B near 1.0, use dlgaob() which applies a Mercator series for higher accuracy.

Parameters
ANumerator; must be > 0.
BDenominator; must be > 0.
Returns
\(\ln(A/B)\), or 0 on domain error.
Note
Error codes: 1 = overflow, 2 = A <= 0 or B <= 0 or A/B <= 0.
See also
dlgaob() for the series-accurate variant.
