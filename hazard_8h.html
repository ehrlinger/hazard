Detailed Description

HAZARD-specific definitions: HAZARD/EXTERN macro, hzrstr, version.

The #ifdef HAZARD / #define EXTERN pair works like the STRUCT/EXTERN pattern in structures.h, but gates hazard.c-specific storage:

// In hazard.c only:
#define HAZARD
#include "hazard.h" // allocates EXTERN variables declared below
// In other .c files:
#include "hazard.h" // gets extern declarations
