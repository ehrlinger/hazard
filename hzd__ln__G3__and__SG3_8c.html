Detailed Description

Late-phase shaping function G3 and hazard shaping function SG3.

Implements four cases of the late-phase cumulative hazard shaping function \(G_3(t)\) and its time derivative \(SG_3(t)\).

The general 4-parameter form:

\[ G_3(t) = \left[\left(1 + \left(\frac{t}{\tau}\right)^\gamma\right)^{1/\alpha} - 1\right]^\eta \]

\[ SG_3(t) = G_3(t)^{1-1/\eta} \cdot \left(1+\left(\frac{t}{\tau}\right)^\gamma\right)^{(1-\alpha)/\alpha} \cdot \left(\frac{t}{\tau}\right)^{\gamma-1} \cdot \frac{\gamma\eta}{\tau\alpha} \]

When \(\alpha \to 0\) (g3flag=2 or 4):

\[ G_3(t) = \left[e^{(t/\tau)^\gamma} - 1\right]^\eta \]

FORTRAN origin: model91/dlg3 (DLG3 subroutine). TemporalHazard R equivalent: hzd_G3() in the R package.

void hzd_ln_G3_and_SG3 ( void  )

Compute \(\ln G_3(t)\) and \(\ln SG_3(t)\) (late-phase shaping functions).

Uses global structs: reads Late (tau, gamma, alpha, eta, g3flag) and HazG3.T; writes HazG3.lnG3 and HazG3.lnSG3.

The late-phase shaping function \(G_3(t)\) is a 4-parameter model based on a special case of the hypergeometric series:

\[ G_3(t) = \left[\left(1 + \left(\frac{t}{\tau}\right)^\gamma\right)^{1/\alpha} - 1\right]^\eta \]

Four cases selected by Late.g3flag:

g3flag Condition Notes
1 \(\alpha \neq 0\), \(\gamma\eta = 2\) Generic, constrained
2 \(\alpha = 0\), \(\gamma\eta = 2\) Exponential, constrained
3 \(\alpha \neq 0\) Generic, unconstrained
4 \(\alpha = 0\) Exponential, unconstrained

When \(\alpha \to 0\) (g3flag 2 or 4), the model reduces to:

\[ G_3(t) = \left[e^{(t/\tau)^\gamma} - 1\right]^\eta \]

Precondition
setg3() must have been called to set Late.g3flag.
HazG3.T must be set to the evaluation time \(t > 0\).
Postcondition
HazG3.lnG3 and HazG3.lnSG3 are set.
Note
Calls hzd_Error() via ErrorPassBack on domain errors.
