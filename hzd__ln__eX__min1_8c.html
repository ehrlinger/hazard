Detailed Description

Numerically stable computation of \(\ln(e^x - 1)\), \(x > 0\).

Avoids catastrophic cancellation when \(x\) is small (where \(e^x \approx 1\)) by switching to the Taylor series \(e^x - 1 = \sum_{k=1}^{N} x^k / k!\), truncated when the next term falls below machine precision.

FORTRAN origin: math91/dlexm1 — E.H. Blackstone, March 1986; FORTRAN 77 translation from earlier work by C.R. Katholi, Ph.D. Verified December 3, 1989; November 1994 revisions by E.H. Blackstone.

double hzd_ln_eX_min1 ( double  X)

Compute \(\ln(e^x - 1)\) with domain check and cancellation avoidance.

For \(x \geq\) LnLim.maxOneSig ( \(\approx 74\)), \(e^x \gg 1\) so the result is returned as \(x\) directly. For \(x \leq\) LnLim.absMin, underflow is handled by returning 0. Near \(x = 0\) where \(e^x \approx 1\), a Taylor series \(e^x - 1 = \sum_{k=1}^{N} x^k / k!\) is used to avoid cancellation.

Parameters
XArgument; must be \(> 0\).
Returns
\(\ln(e^x - 1)\), or 0 on underflow.
Note
Overflow ( \(x \geq\) LnLim.max): silently returns \(x\). Underflow (result rounds to zero): silently returns 0. No error code is set; this function never calls hzd_Error().
